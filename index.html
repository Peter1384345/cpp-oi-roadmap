ROADMAP

四步走，别跳级

路线图就一句话：先把基础写稳，再上难度。每一步都有明确的「学什么 → 练什么 → 怎么检验」，别一上来就啃省选题，那样只会怀疑人生。

S0

语言基础 · 零基础入门

入门

从 Hello World 到 STL 容器，建立 C++ 语法与编程思维基础，为竞赛打下地基。

  • 环境搭建 / 输入输出 / 语法核心
  • 数组 · 字符串 · 函数 · 结构体
  • STL 入门：vector / stack / queue
建议时长：1~2 个月进入阶段 →
S1

CSP-J · 入门级

普及

信息学竞赛第一座正式考场：初赛（笔试）+ 复赛（上机 4 题），掌握枚举、模拟、搜索与基础 DP。

  • 枚举 · 模拟 · 贪心 · 二分
  • DFS / BFS 搜索入门
  • 背包 DP · 线性 DP · 简单图论
建议时长：3~6 个月进入阶段 →
S2

CSP-S · 提高级

提高

晋级更高难度的战场：进阶数据结构与图论、状态压缩 DP、字符串算法与数论正式登场。

  • 线段树 · 树状数组 · 并查集
  • 最短路 · 最小生成树 · 强连通分量
  • 状压 DP · KMP · 数论进阶
建议时长：6~12 个月进入阶段 →
S3

NOIP · 省赛（最难关卡）

省选级

全国青少年信息学奥林匹克联赛（省赛），综合运用全部高阶知识：网络流、树链剖分、多项式与思维构造题。

  • 网络流 · 树链剖分 · 可持久化
  • 斜率优化 · FFT/NTT 多项式
  • 思维构造 · 博弈 · 概率期望
建议时长：1 年+进入阶段 →
