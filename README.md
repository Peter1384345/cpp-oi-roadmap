# 🚀 C++ 竞赛全攻略 · CSP-J → CSP-S → NOIP 学习路线图与资源整合

从 **CSP-J**（最简单）到 **NOIP**（最难）的 C++ 信息学竞赛**完整学习路线图**与**学习资源整合网**，纯前端静态站点，自带动态粒子网络特效，科技感十足。

## 🌐 在线访问
- **GitHub Pages**: https://peter1384345.github.io/cpp-oi-roadmap/

## 📚 内容涵盖
| 模块 | 说明 |
|------|------|
| 四阶段路线总览 | S0 语言基础 → S1 CSP-J → S2 CSP-S → S3 NOIP |
| 阶段详细攻略 | 每阶段学习目标 / 核心知识点 / 配套书籍 |
| 资源整合中心 | 在线题库 · 经典书籍 · 知识库 · 视频课程 · 效率工具 |

| FAQ | 零基础规划 / 刷题策略 / OI 赛制 / 升学平衡等 10 问 |

## ✨ 技术特性
- 🕸️ **Canvas 动态粒子网络**：粒子漂移 + 邻近连线 + 鼠标交互引力 + 光晕
- 🌌 暗色科幻主题：霓虹渐变、玻璃拟态卡片、网格背景
- 📱 完全响应式，移动端自适应
- ⚡ 零依赖纯静态：HTML + CSS + Vanilla JS，双击 index.html 即可离线浏览

## 📁 目录结构
```
cpp-oi-roadmap/
├── index.html            # 主页面
├── css/style.css         # 科技感主题样式
├── js/particles.js       # 粒子网络特效
├── js/main.js            # 交互逻辑（Tab/过滤/FAQ/动画）
└── data/
    ├── stages.js         # 四阶段详细攻略数据
    ├── resources.js      # 学习资源数据
    ├── calendar.js       # 竞赛日历数据
    └── faq.js            # 常见问题数据
```
